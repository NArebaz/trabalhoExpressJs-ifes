# Sistema de Biblioteca 📚

## Sobre o projeto

O objetivo deste projeto é desenvolver um sistema de gerenciamento de biblioteca utilizando JavaScript, Node.js e Express.js.

O sistema permitirá cadastrar, consultar, atualizar e excluir livros, além de registrar usuários e controlar empréstimos e devoluções.

## Funcionalidades

- Cadastro e listagem de livros.
- Pesquisa de livros.
- Atualização e exclusão de livros.
- Cadastro de usuários.
- Registro de empréstimos e devoluções.
- Controle da disponibilidade dos livros.

## Objetivo de aprendizado

Este projeto tem como objetivo praticar a lógica de programação, aprender a utilizar o Node.js e o Express.js e desenvolver minhas habilidades em programação backend.
