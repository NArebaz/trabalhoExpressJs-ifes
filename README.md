# 📚 Sistema de Biblioteca

## 📌 Sobre o projeto

Este projeto consiste em um sistema de biblioteca desenvolvido para praticar lógica de programação, JavaScript e Express.js.

O objetivo é criar um sistema capaz de organizar livros, usuários e empréstimos, facilitando o gerenciamento de uma biblioteca.

## 🛠️ Tecnologias utilizadas


- Node.js
- Express.js
- HTML



## 📂 Organização dos arquivos

```text
TRABALHO EXPRESS/
├── app.js
├── cadastroDeLivros.js
├── package.json
├── package-lock.json
└── node_modules/
```

- **app.js:** arquivo principal responsável por iniciar o servidor e conectar as rotas.
- **cadastroDeLivros.js:** arquivo responsável pelas rotas e funcionalidades relacionadas aos livros.
- **package.json:** contém informações e dependências do projeto.

## ▶️ Como executar o projeto

**1.** Instale o [Node.js](https://nodejs.org/).

**2.** Abra o terminal na pasta do projeto.

**3.** Instale as dependências:

```bash
npm install
```

**4.** Inicie o servidor:

```bash
node app.js
```

**5.** Acesse no navegador:

```text
http://localhost:80
```

## 🎯 Objetivo de aprendizagem

O projeto está sendo desenvolvido como prática dos estudos de backend, com foco na organização do código, criação de rotas, recebimento de dados de formulários e validação de informações.

Novas funcionalidades serão implementadas conforme o avanço dos estudos.
